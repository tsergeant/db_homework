# Database Systems

Welcome to **Database Systems** — a course for Computer Science majors focusing on **modern database management systems**.

In this course, you’ll learn **SQL**, **PL/PgSQL**, **JDBC**, **MongoDB scripting** and will interace with two DBMSs: **PostgreSQL** and **MongoDB**.
